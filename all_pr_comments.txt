**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Allow the workspace body to scroll**

When subtitles are present, this column contains the wizard, dashboard, and a `.workspaceWorkbenchArea` with `min-height: 400px`; at the configured 680px minimum window height, those blocks plus padding and gaps exceed the available vertical space. Because this column has no vertical scrolling and its parent `.workspaceModernLayout` hides overflow, the bottom of the subtitle editor/list is clipped and unreachable. Please add vertical scrolling here or let the workbench shrink.

**<sub><sub>![P3 Badge](https://img.shields.io/badge/P3-lightgrey?style=flat)</sub></sub>  Bundle the font instead of importing it**

In the packaged renderer, `index.html` sets a CSP of `style-src 'self' 'unsafe-inline'` and no `font-src`, so this external Google Fonts `@import` is blocked and the Inter font never loads, while each launch logs a CSP violation. Since this is a desktop/offline app, please self-host the font asset or remove the external import and rely on the existing fallback stack.

**<sub><sub>![P2 Badge](https://img.shields.io/badge/P2-yellow?style=flat)</sub></sub>  Render the empty subtitle state**

If transcription completes with a subtitle document that contains zero segments, such as silent media or audio where ASR found no speech, `hasRecognizedSubtitles` is false so the workbench is never mounted.

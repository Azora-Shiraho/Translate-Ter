## 中文

### 更新内容

- 发布 `2.2.0` 正式版，整合自 `master` 分叉以来 `develop` 分支上的全部稳定改动。
- 完成批量处理工作流：增加原生批量队列、前端批量任务页、任务摘要与状态展示，并修复取消、重试、空闲状态切换等关键流程问题。
- 支持批量任务自动导出字幕：新增导出语言后缀、避免覆盖已有文件，并补齐跨平台导出路径与完成态修复。
- 重构桌面端界面：重做工作区双栏布局、设置页与批量处理页，更新 toast、提示卡与主题样式，并补齐可访问性、本地化和浅色主题适配。
- 强化打包与发布稳定性：修复 Electron 打包后 CSS 因 `crossorigin` 导致的加载失败、桌面样式回退问题，以及 macOS x64 发布 runner 配置问题。
- 补充项目基础信息与文档：新增 MIT 许可证，重写双语 README，整理 UI 指南，并移除已完成的架构更新文档。

### macOS Gatekeeper 说明

- 当前 macOS 发布包尚未签名和公证，因此 Gatekeeper 可能提示“无法验证开发者”或直接阻止打开。
- 这是因为 CI 生成的社区发布产物暂未附带 Apple Developer ID 证书和 Apple notarization 票据，属于当前发布流程下的预期现象。
- 图形界面绕过方式：
  1. 打开 `系统设置`。
  2. 进入 `隐私与安全性`。
  3. 找到被拦截的 Translate-Ter 提示并选择 `仍要打开`。
  4. 在确认弹窗中选择 `打开`。
- 也可以在 Finder 中按住 Control 点击应用，选择 `打开`，再在弹窗中确认 `打开`。
- 如果 macOS 提示应用“已损坏”，并且 `隐私与安全性` 中没有出现 `仍要打开` 按钮，请在终端执行：

```bash
xattr -dr com.apple.quarantine "/Applications/Translate-Ter.app"
```

- 这个命令只会移除 app bundle 上的 quarantine 隔离标记，不会给应用签名、公证，也不会修改应用代码。请只对从本项目 GitHub Releases 页面下载的产物使用这些绕过方式。

## English

### What's New

- Release `2.2.0`, promoting all stable work from `develop` since it diverged from `master`.
- Complete the batch-processing workflow with a native batch queue, a dedicated batch task page, richer status and summary views, and fixes for cancel, retry, and idle-state transitions.
- Add automatic subtitle export for batch jobs, including language suffixes, overwrite protection, and cross-platform export path and completion-state fixes.
- Redesign the desktop UI across the workspace, settings, and batch pages, refresh toast and prompt-card styling, and improve accessibility, localization, and light-theme support.
- Harden packaging and release reliability by fixing Electron CSS loading failures caused by `crossorigin`, desktop style fallback regressions, and the macOS x64 release runner configuration.
- Improve project documentation and metadata with an MIT license, a rewritten bilingual README, refreshed UI guidelines, and removal of completed architecture-update drafts.

### macOS Gatekeeper Notes

- Current macOS packages are unsigned and not notarized, so Gatekeeper may warn that the app is from an unidentified developer or block it from opening.
- This is expected for community release artifacts produced by CI without an Apple Developer ID certificate and an Apple notarization ticket.
- GUI override path:
  1. Open `System Settings`.
  2. Go to `Privacy & Security`.
  3. Find the blocked Translate-Ter message and choose `Open Anyway`.
  4. Confirm `Open` in the dialog.
- You can also Control-click the app in Finder, choose `Open`, and then confirm `Open`.
- If macOS says the app is damaged and `Privacy & Security` does not show an `Open Anyway` button, run this command in Terminal:

```bash
xattr -dr com.apple.quarantine "/Applications/Translate-Ter.app"
```

- This command only removes the quarantine attribute from the app bundle. It does not sign, notarize, or otherwise modify the application code. Only use these overrides for artifacts downloaded from this project's GitHub Releases page.

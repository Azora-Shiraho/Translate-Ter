# Translate-Ter UI & UX 设计准则说明文档

本文档定义了 **Translate-Ter** 桌面端前台界面的核心 UI 与 UX 交互视觉规范。整个系统采用现代**黑曜石磨砂玻璃态（Obsidian Glassmorphism）**与**专业生产力 IDE 双栏布局**，致力于为极客和专业音视频创作者提供最高水准的视听翻译体验。

---

## 🎨 1. 色彩与材质规范 (Color & Surfaces)

为了实现沉浸式的低反差高级暗黑美学，界面采用极暗的黑灰色阶，杜绝纯黑（#000）或普通的浅灰色。

### 1.1 背景与色阶 (Color Scale)
- **全局底色 (`--tt-surface-app`)**：`#050506`（纯夜深灰，提供柔和的视疲劳保护）。
- **面板底色 (`--tt-surface-panel`)**：`#0d0e12`（黑曜石主面板色，用于侧边栏与卡片容器）。
- **悬浮卡片 (`--tt-surface-panel-soft`)**：`#16171d`（带有半透明玻璃质感，悬浮时位移并溢出阴影）。
- **激活边框 (`--tt-accent`)**：`#6366f1`（主题靛蓝，带微光阴影用于激活指示线）。

### 1.2 文字层级 (Typography)
- **强强调 (`--tt-text-strong`)**：`#ffffff`（用于标题、高亮数值与主按钮字）。
- **普通阅读 (`--tt-text-body`)**：`#b3b3b8`（用于卡片描述、正文内容）。
- **次要弱化 (`--tt-text-muted`)**：`#6e6e73`（用于表单标注、副标题、路径等）。

### 1.3 边框与阴影 (Borders & Shadows)
- **极细边线 (`--tt-border-soft`)**：`rgba(255, 255, 255, 0.06)`（用于静默分割，高透光率）。
- **强轮廓线 (`--tt-border-strong`)**：`rgba(255, 255, 255, 0.12)`（用于普通 Hover 或激活轮廓）。
- **卡片圆角 (`--tt-radius-card`)**：`12px`；输入框与小标签为 `8px`。

## 🗂️ 2. 工作流与排版布局 (Layout Architectures)

### 2.1 双栏 IDE 级工作台 (Dual-Column Desktop Stage)
- **左侧流式控制台 (340px 固宽)**：作为管线的集中地，承载文件拾取、参数预设、进度指引和环境监控。
- **右侧全屏编辑器 (自适应)**：将 100% 的纵向高度供给字幕时间轴编辑器（`SubtitleWorkbench`）。彻底解决头部向导抢占内容高度、导致编辑区视野狭窄的局限。
- **空状态指引 (Empty State)**：在没有加载数据时，主舞台必须展示高品质的 3D 浮动圆环/时钟等科技感微光动画，并用单句指令指引用户。

### 2.2 智能手风琴自动折叠联动 (Accordion Stepper)
- 为了保证控制栏能一屏展示完整生命周期（选择媒体 -> 语音识别 -> 翻译字幕 -> 导出），必须实现**状态感知手风琴**：
  - 未激活的步骤高度折叠，仅保留 1 行简练的已选配置信息（如 ASR 引擎名、语言对、文件名）。
  - 当前进行中或运行中的步骤卡片高亮展开，显示完整的控制按钮和进度指标。
  - 支持用户在头部随时手动点击切换展开。

## 🚀 3. 动效与微交互 (Animations & Micro-interactions)

动态交互能赋予静态界面“生命感”，在数据处理与等待阶段，必须运用以下微动效：

### 3.1 彩虹流体进度条 (Rainbow Fluid Progress)
- 进度条宽度变化采用 `transition: width 0.3s cubic-bezier(0.4, 0, 0.2, 1)`；
- 填充层使用彩色渐变，配合 `background-size: 200%` 触发横向循环流光动画，表现算力正在高速响应。

### 3.2 雷达双层呼吸灯 (Radar Wave Pulse)
- 运行中的步骤和任务，标题旁边闪烁一个 `radar-badge`；
- 使用 `::after` 伪类设置 2 像素的 accent 环，并使用 `radar-pulse-anim 1.6s infinite` 进行向外扩散与淡出，指示后台服务存活。

### 3.3 仪表盘 3D 自转齿轮 (3D Spinning Gear)
- 进行后台 IO/计算时，进度指标图标（如 Clock 或 Gear）必须追加 `running-spin` 动画；
- 通过 `transform: rotate(360deg)` 顺时针匀速持续旋转，给用户明显的运行反馈。

## 🛡️ 4. 界面安全排版规范 (CSS Spacing Safety)

### 4.1 防止列表边缘剪裁 (Scroll Area Padding)
- **规则**：凡是配置了 `overflow-y: auto` 的横纵滚动槽（如字幕列表、批量任务表），其子卡片如果包含 `box-shadow`、`border-radius`，容器的 `padding` 必须预留至少 `4px`。
- **反例**：无左内边距会导致滚动栏刚好贴紧卡片左边缘，在激活高亮或滚动时，圆角和阴影会被物理剪裁为直角，视觉呈现锯齿。

### 4.2 浮动定位避障 (High Z-Index Overlay)
- **规则**：所有临时浮动面板（如翻译引擎卡片、悬浮提示框）的 `z-index` 必须显式声明在最顶层（例如 `z-index: 100` 或以上）；
- 控制相对于鼠标/光标的碰撞边界，防止卡片被下层的原生选择器或文字重叠遮挡。
